# Дневник тренировок SportCLUB

Дневник обслуживает `workouts-service` через маршрут Gateway `/api/workouts/**`. Данные хранятся в PostgreSQL в базе `sportclub_workouts`. Клиент определяется по подписанному JWT. Для работы с дневником достаточно войти в аккаунт.

## Программы и упражнения

Каталог содержит 15 упражнений и две общие программы «Всё тело · Тренировка A/B». Начальные веса в шаблонах равны нулю: клиент задаёт собственные рабочие веса. Можно собрать свою программу из 1–12 разных упражнений, указав 1–6 подходов и 1–100 повторений.

Веса записываются в килограммах с точностью до сотых в диапазоне 0–500. Нулевой дополнительный вес подходит для упражнений с собственным весом. Это ограничения полей дневника, а не рекомендации по нагрузке.

Программы после создания не редактируются; можно создать новую и удалить старую. Общие шаблоны нельзя удалить. Чужие программы недоступны. Удаление собственной программы не удаляет историю: начатая тренировка содержит независимый снимок названий упражнений, подходов и плановых значений.

## Сохранение и история

Одновременно разрешена одна активная тренировка на клиента. При старте блокируется служебная строка клиента, поэтому два одновременных запроса не создадут два черновика. Сохранение подхода, завершение и отмена блокируют строку тренировки, исключая изменение после завершения.

Отмеченные подходы учитываются в результате; снять отметку можно до завершения. Для завершения требуется хотя бы один выполненный подход. После завершения результат становится неизменяемым. История возвращает последние 100 завершённых тренировок клиента. Дата показывается в московском часовом поясе, время хранится с часовым смещением.

Предыдущий результат — последний выполненный подход того же упражнения из последней завершённой тренировки этого клиента. Незавершённые подходы, черновики и результаты других клиентов не учитываются. Предыдущий результат фиксируется при старте новой тренировки.

## Итоги тренировки

Объём считается как сумма `дополнительный вес × повторения` по выполненным подходам. Например, 20 кг × 10 повторений дают 200 кг учтённого объёма. Значение не учитывает массу тела, амплитуду, работу на тренажёрах и различия между оборудованием; это показатель для сравнения собственных записей.

Длительность можно указать вручную в пределах 1–360 минут. Если она не передана, сервер рассчитывает время от старта до завершения с округлением вверх до целой минуты, минимум 1. Для слишком долго открытого черновика потребуется указать фактическую длительность.

Вес тела для оценки расхода калорий вводится по желанию при завершении; без него оценка отсутствует. Используется приближённая формула `3,5 × 3,5 × вес тела / 200 × минуты`. Первый коэффициент — 3,5 MET для силовой тренировки с несколькими упражнениями (код 02054 в [Compendium of Physical Activities 2024](https://pacompendium.com/wp-content/uploads/2024/03/4_2024_adult-compendium-tracking-guide-1-2024.pdf)). Определение MET приведено на [сайте Compendium](https://pacompendium.com/). Например, для 80 кг и 30 минут получается около 147 ккал.

Это ориентировочная общая оценка, а не измерение расхода энергии: она не определяет фактическую интенсивность, состав тела и индивидуальный обмен веществ. В интерфейсе результат обозначен как приблизительный.

## API

| Метод | Путь после `/api/workouts` | Операция |
|---|---|---|
| GET | `/exercises` | Каталог упражнений |
| GET, POST | `/programs` | Общие/собственные программы, создание собственной |
| DELETE | `/programs/{id}` | Удаление собственной программы |
| POST | `/sessions` | Начать тренировку |
| GET | `/sessions/active` | Активная тренировка; пустой ответ 200, если её нет |
| GET | `/sessions` | История завершённых тренировок |
| GET | `/sessions/{id}` | Снимок своей тренировки |
| PUT | `/sessions/{id}/sets/{setId}` | Сохранить вес, повторения и отметку подхода |
| POST | `/sessions/{id}/finish` | Завершить тренировку |
| DELETE | `/sessions/{id}` | Отменить активный черновик |

OpenAPI: [документация сервиса тренировок](http://localhost:8080/api/workouts/v3/api-docs). Чужие ресурсы возвращают 404, запросы без входа — 401, конфликт состояния — 409, неверные данные — 400.
