# Личные показатели SportCLUB

Вода, сон, вес и рост сохраняются в отдельной базе `wellness-service`. Клиент определяется по подписанному JWT: его идентификатор не принимается из формы. Все операции требуют входа; действующий абонемент для личных записей не нужен.

## Записи по дням

День определяется в часовом поясе `Europe/Moscow`. Можно выбрать дату с 1 января 2000 года по сегодняшний день включительно. Будущие даты не принимаются. История возвращает каждый день выбранного периода, включая дни без записей; длина периода — не более 31 календарного дня включительно.

У пустого дня вода равна нулю, список порций пуст, а сон, вес, рост и ИМТ равны `null`. Данные прошлого дня не подставляются как сегодняшние. Сон и измерения тела можно заменить повторным сохранением или удалить независимо от воды.

## Вода

Каждая порция — отдельная запись с идентификатором, объёмом в миллилитрах и временем добавления. Итог дня — сумма сохранённых порций. Ошибочно добавленную порцию можно удалить; чужая запись недоступна и возвращает 404.

Личная цель задаётся самим клиентом. Начальное значение интерфейса — 2000 мл; это настраиваемое значение приложения, а не индивидуальная рекомендация. Цель общая для аккаунта: после её изменения дни истории показываются относительно текущей цели.

Ограничения ввода: порция 1–2000 мл, цель 250–10000 мл, сумма записей за день не больше 10000 мл. Это технические пределы полей дневника. Проверка суммы и сохранение выполняются с блокировкой данных клиента, чтобы одновременные запросы не обходили ограничение.

## Сон, вес и ИМТ

Сон записывается общей длительностью за выбранную дату в целых минутах, от 15 до 1440. Интерфейс переводит часы в минуты. Это ручной дневник; приложение не получает данные с часов или телефона.

Для расчёта ИМТ клиент сохраняет вместе вес в килограммах и рост в сантиметрах. Допустимые значения полей: вес 30–300 кг и рост 100–250 см, до двух знаков после запятой. Каждая дата содержит собственный снимок обоих значений: изменение сегодняшнего роста не пересчитывает прошлые измерения.

Формула: `ИМТ = вес, кг / (рост, м × рост, м)`. Результат округляется до одного знака после запятой по правилу HALF_UP. Например, 80 кг при росте 200 см дают 20,0, а 81 кг при 180 см — 25,0. Приложение показывает вычисленный индекс без медицинских категорий или диагноза.

## API

Все пути ниже начинаются с `/api/wellness`.

| Метод | Путь | Тело или параметры | Результат |
|---|---|---|---|
| GET | `/day` | Необязательный `date=YYYY-MM-DD`, по умолчанию сегодня | День |
| POST | `/water` | `{ "date": "2026-10-31", "amountMl": 250 }` | 201, обновлённый день |
| DELETE | `/water/{id}` | UUID собственной порции | 204 |
| PUT | `/settings` | `{ "waterGoalMl": 2500 }` | Сегодняшний день с новой целью |
| PUT | `/days/{date}/sleep` | `{ "sleepMinutes": 480 }` | Обновлённый день |
| DELETE | `/days/{date}/sleep` | — | 204 |
| PUT | `/days/{date}/body` | `{ "heightCm": 200, "weightKg": 80 }` | Обновлённый день |
| DELETE | `/days/{date}/body` | — | 204 |
| GET | `/history` | Обязательные `from` и `to`, включительно, не более 31 дня | Массив дней |

Ответ дня содержит `date`, `today`, `waterGoalMl`, `waterTotalMl`, `waterEntries`, `sleepMinutes`, `weightKg`, `heightCm`, `bmi`. Запись воды содержит `id`, `amountMl`, `createdAt`.

Запрос без входа возвращает 401, неверные поля или даты — 400, попытка обращения к чужой порции — 404. Формат ошибки: `code`, `message`, `requestId`. Заголовок `X-Request-ID` проходит через Gateway и сервис. [OpenAPI сервиса](http://localhost:8080/api/wellness/v3/api-docs) содержит схему Bearer JWT и описание операций.

## Проверка

После локального запуска сервисов:

```powershell
.\scripts\test-wellness-flow.ps1
```

Сценарий создаёт два тестовых аккаунта, проверяет вход, независимую цель воды, сумму и удаление порций, сон, расчёт ИМТ, историю и изоляцию данных. Также проверяются неверные значения, будущая дата, слишком длинная история, дневной предел ввода, идентификатор запроса и защита API в OpenAPI. В блоке `finally` удаляются порции и дневные показатели тестового аккаунта, цель возвращается к 2000 мл. Остаются только два учебных аккаунта без личных записей.
