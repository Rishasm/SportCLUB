# Дневник питания

В личном кабинете откройте «Питание», выберите дату, приём пищи и продукт из справочника. Сохраните вес порции. Дневник покажет калории, белки, жиры и углеводы за порцию, приём пищи и день.

Справочник из 24 продуктов хранит ориентировочные значения на 100 г. Например, 150 г варёного риса с базовым значением 130 ккал дают 195 ккал. Сухой и варёный рис учитываются отдельно.

| Операция | Запрос через Gateway |
|---|---|
| Справочник | `GET /api/nutrition/foods` |
| Итоги дня | `GET /api/nutrition/day?date=ГГГГ-ММ-ДД` |
| Добавить порцию | `POST /api/nutrition/entries` |
| Изменить порцию | `PUT /api/nutrition/entries/{id}` |
| Удалить порцию | `DELETE /api/nutrition/entries/{id}` |

Для операций требуется вход. Записи выбираются по идентификатору пользователя из JWT. Сервис хранит справочник и порции в схеме `nutrition` базы `sportclub_wellness`. Конфигурация поступает из Config Server, сервис обнаруживается через Eureka. [OpenAPI через Gateway](http://localhost:8080/api/nutrition/v3/api-docs).
