# Итоговая проверка SportCLUB

| Пункт ТЗ | Что проверяется |
|---|---|
| Минимум три бизнес-микросервиса | Пять сервисов отвечают через Gateway и подключены к PostgreSQL |
| Spring Cloud Config | Каждый сервис сообщает, что получил централизованную конфигурацию |
| Eureka и Gateway | Сервисы зарегистрированы, все пять маршрутов доступны |
| Circuit Breaker | При остановке wellness маршрут возвращает 503, остальные работают, данные доступны после восстановления |
| Actuator, логирование и OpenAPI | Диагностика, документация API и прохождение `X-Request-ID` |

## Как повторить

На подготовленной PostgreSQL соберите проект с `scripts/build.ps1`, запустите его через `scripts/start-local.ps1` и откройте [диагностику](http://localhost:8080/diagnostics.html).

- `scripts/smoke-test.ps1` проверяет инфраструктуру и API пяти сервисов.
- `scripts/test-booking-flow.ps1`, `scripts/test-workouts-flow.ps1` и `scripts/test-wellness-flow.ps1` проверяют основные пользовательские сценарии.
- `scripts/test-resilience.ps1` временно останавливает и восстанавливает сервис показателей и проверяет сохранность записи.
- Для ручной проверки медиа откройте главную, карточку силового занятия и карточку растяжки. В карточках запустите MP4 в разделе «Техника упражнений».

## Результаты от 8 ноября 2026

- Полная Maven-сборка прошла. Все 46 тестов завершились без ошибок и пропусков.
- Стартовая диагностика подтвердила пять маршрутов, PostgreSQL, Config Server, Eureka, OpenAPI и прохождение идентификатора запроса.
- Через Gateway проверены права сотрудников, CRUD расписания, уведомления, профиль, тестовая карта, СБП, повтор платежа, бронирования и три дневника. Сценарии использовали отдельные тестовые аккаунты.
- В Edge проверены три фотографии, фактическое воспроизведение обоих MP4, встроенная анимация приседания и новые экраны на ширине 390 и 320 px.
- При остановке `wellness-service` его маршрут вернул 503, а остальные четыре продолжили отвечать 200. После восстановления та же запись воды осталась доступна с тем же JWT.
